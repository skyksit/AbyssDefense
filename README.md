# Abyss Defense

기지에서 자원을 캐고 가공하고 기술을 연구한 뒤, 심연을 하나 골라 100개 지역을 차례로 점령해 내려가는 타워 디펜스 게임. Unity 6000.6.5f1, 모바일 세로 화면 우선.

장르와 구조(타일 맵, 블록 정의/설치 건물 분리, 웨이브 식, 흐름장 길찾기)는 Mindustry 를 분석해 참고했다. 코드·그림·이름·맵은 모두 새로 만든 것이며 Mindustry(GPL-3.0)의 것은 쓰지 않는다.

## 게임 흐름

타이틀 → **기지** → 심연 선택(잿불·서리·독늪) → 지역 지도(1~100, 번호순 해금) → 가져갈 자원을 정하고 출격 → 지역 전투 → 결과 → 기지

### 기지 (심연과 무관)
- 자원은 7종이다. 원광 3종(철광·황석·심연 결정)은 채굴장이 캐고, 가공 자원 4종(강철·회로·화약·심연 합금)은 가공 건물이 원광을 바꿔 만든다
- 철광·황석·결정 채굴장을 강화하면 **분당 생산량**이 늘고, 창고를 강화하면 보관 한도가 늘어난다. 결정 채굴장은 지역 10 을 점령해야 지을 수 있다
- **가공 건물**: 제련소(철광 3 → 강철 1, 지역 2), 회로 조립소(철광 2 + 황석 1 → 회로 1, 지역 4), 화약 합성소(황석 2 → 화약 1, 지역 7), 합금 융합로(강철 2 + 심연 결정 1 → 심연 합금 1, 지역 14). 괄호 안의 지역을 점령하면 지을 수 있고, 강화하면 분당 처리량이 늘어난다. 원료를 아끼고 싶으면 '가동 중' 버튼으로 멈춘다. 보유 자원 칸의 숫자는 채굴에서 가공 원료를 뺀 분당 증감이다
- 생산은 어느 화면에 있든, 게임을 꺼 두어도(최대 8시간치) 계속 쌓인다. 창고 한도까지만 쌓인다
- **연구소**: 기지를 뿌리로 위아래로 뻗는 **연구 트리**다. 위쪽 가지는 포탑·방어(포탑 화력 → 박격포 기술 → 결정포 기술, 포탑 화력 → 조준 장치 → 탄약 절약, 강화 장갑 → 핵 보호막 / 건설 드론), 아래쪽 가지는 보급과 유닛(출격 물자 → 채굴 기술 → 전리품 회수, 로봇 공장 기술 → 비행장 기술 → 조선소 기술 / 지휘 체계 / 지원 공방 기술 / 다리 공방 기술 / 기체 개량 I → II → III → IV / 기체 강화)
  - 앞 연구를 1단계 이상 마쳐야 다음 연구가 드러난다 (그 전에는 '?'). 드러났어도 정해진 지역을 점령하기 전에는 자물쇠로 잠겨 있다
  - 노드 테두리: 흰색 = 지금 연구할 수 있다, 붉은색 = 자원이 모자란다, 보라색 = 연구함, 금색 = 끝까지 연구함. 이음선은 연구한 곳까지 금색이 된다
  - 노드를 탭하면 아래 창에 효과와 남은 비용(넣을 수 있는 양 / 남은 양)이 나온다. 자원이 모자라도 **가진 만큼 먼저 넣어 둘 수 있고**, 다 채우면 단계가 오른다
  - 한 손가락으로 끌어 옮기고, 두 손가락 벌리기·휠로 확대한다. 연구는 모든 심연에 함께 적용된다

### 출격
- 지역 정보 창에서 가진 자원 종류마다 가져갈 양을 정한다 (한도 400, '출격 물자' 연구 단계마다 +150). 그만큼 기지 재고에서 빠진다
- 빈손으로 가도 기본 보급 철광 150 은 받는다

### 지역 전투
- 짓는 것: 속사포, 방벽, 박격포, 결정포, 로봇 공장, 비행장, 지원 공방, 다리 공방, 조선소(이상 연구 필요), 강철 방벽. 비용은 핵에 있는 자원에서 나간다
- **유닛 공장**: 다 지어진 공장은 고른 유닛을 핵의 자원으로 계속 만든다. 비용은 생산을 시작할 때 나간다. 공장을 탭하면 뜨는 창에서 만들 유닛을 고르거나 생산을 멈추고, '집결 지점 옮기기'를 누른 뒤 맵을 탭해 유닛이 모일 곳을 정한다. 유닛은 모두 25종이다
  - 로봇 공장(지상 공격): 척후 로봇 → 돌격 로봇(근거리 관통) → 중장 로봇(범위 피해) → 공성 로봇(사거리 7.5, 적 건물에 2.5배, 공중 못 쏨) → 거신 로봇. 벽은 돌아가고 아군 건물은 넘어 다닌다
  - 비행장(공중 공격): 정찰기 → 폭격기(지상만 공격) → 강습기 → 전함 → 모함. 지형을 무시하고 곧장 날아간다
  - 지원 공방: 정비 로봇(둘레 3.2칸의 아군 유닛·건물을 고친다), 방패 로봇(3칸 안 아군 유닛이 받는 피해 −35%), 수리 드론(가장 많이 상한 건물로 날아가 고친다, 무기 없음), 수송기(공격 태세일 때 걸어가는 유닛을 한도 6칸까지 실어 적 출현 지점 앞에 내려놓는다), 채굴 드론(집결 지점에서 가장 가까운 벽을 5초 캐서 철광 8 을 핵으로 나른다. 세 번에 한 번은 황석 4. 무기 없음)
  - 다리 공방: 자폭 벌레(싸고 빠르다, 붙어서 터지며 적 건물에 3배), 등반 로봇(지형 벽을 타 넘어 곧장 간다), 산성 로봇(2단계, 벽을 타 넘고, 사거리 4.5 의 산성 덩어리로 범위 안 지상의 적을 2.5초 동안 절반 속도로 늦춘다. 보스는 절반만 느려지고, 공중은 못 쏜다) → 흡수 로봇(3단계, 벽을 타 넘고, 사거리 3.2 로 짧지만 준 피해의 40% 만큼 스스로를 고친다) → 파편 로봇(4단계, 벽을 타 넘고, 사거리 6.5 의 곡사 포탄이 터지면서 파편 6개가 폭발 범위 밖 2칸까지 튄다. 지상만 겨누지만 파편은 공중의 적도 맞힌다. 적 건물에 1.5배)
  - 조선소(해상): 호수 바로 옆에만 지을 수 있다. 초계정 → 포함(범위 피해) → 구축함(사거리 9 곡사포) → 방전함(4단계, 포 대신 전류로 5.5칸 안의 적 8기를 지상·공중 가리지 않고 한꺼번에 치고, 4칸 안의 아군을 고친다). 함정은 태어난 호수 안에서만 움직이지만 사거리가 길고, 근접하는 지상 적에게는 잘 맞지 않는다
  - **호수**: 모든 맵의 벽 덩어리 일부가 호수다. 지상에서는 벽과 똑같이 막혀 있어 길은 달라지지 않는다
  - **지휘기**(코어 유닛): 핵에서 저절로 나오고 유닛 한도를 차지하지 않는다. 핵을 탭한 뒤 맵을 탭하면 그곳으로 가서 4칸 안의 적을 쏜다. 지휘기에서 4칸 안의 건설 터는 1.5배 빨리 지어진다. 잃으면 20초 뒤 핵에서 다시 나온다
  - 유닛 한도는 4, '지휘 체계' 연구 단계마다 +2. 유닛은 단계만큼 한도를 차지한다 (5단계 = 5칸). 4·5단계는 '기체 개량 III·IV' 연구가 필요하다
  - 유닛은 탄약을 쓰지 않는다. 잃으면 공장이 다시 만든다
- **태세** (위쪽 버튼, 모든 유닛 공통): 방어 = 집결 지점(기본은 핵 바로 옆, 적이 오는 쪽)을 지키며 그 7칸 안에 들어온 적만 쫓는다. 공격 = 가장 가까운 적 출현 지점 앞으로 나가 그 7칸 안의 적과 싸운다. 어느 태세든 바로 곁을 지나는 적은 쏜다
- **방어력**: 받는 피해에서 방어력만큼 빠진다 (최소 20% 는 들어간다). 적(파쇄병·철갑병·군주)의 방어력은 깊은 지역일수록 커져서, 한 발이 약한 속사포보다 박격포·결정포·상위 유닛이 필요해진다. 아군은 유닛과 강철 방벽에 방어력이 있다
- 적은 손이 닿는 곳에 아군 유닛이 있으면 멈춰서 그 유닛부터 친다. 지상의 근접 적은 비행 유닛을 못 친다 (비행체·파쇄병·군주는 친다)
- **건설 시간**: 건물을 놓으면 건설 터가 생기고, 비용에 비례한 시간((20 + 비용) × 5 틱 — 방벽 2.3초, 속사포 4.6초, 박격포 14초, 결정포 31초)이 지나야 완성되어 동작한다. 한 번에 두 곳까지만 놓은 순서대로 지어지고, 비용은 진행되는 만큼 핵에서 조금씩 나간다. 핵에 자원이 없으면 멈춘다. 건설 터는 체력이 15%뿐이라 적에게 쉽게 부서진다. 짓던 것을 철거하면 낸 만큼 전부 돌려받는다. '건설 드론' 연구로 빨라진다
- 포탑은 탄이 떨어지면 핵의 자원을 하나씩 가져다 탄으로 만든다 (속사포 철광, 박격포 황석, 결정포 심연 결정). 핵에 그 자원이 없으면 멈추고 붉은 점이 깜빡인다
- 적을 처치하면 전리품이 핵으로 바로 들어온다
- **적 거점 지역** (15, 25, … 95): 웨이브를 버티는 대신 적 핵을 모두 부숴야 점령한다
  - 출현 지점마다 적 핵이 서 있고, 그 둘레를 적 포탑(유닛을 쏜다)과 적 방벽이 지킨다. 깊은 지역일수록 포탑이 많고 단단하다
  - 웨이브는 적 핵에서 끝없이 나오고 회차마다 강해진다. 다섯 회차마다 심연 대장이 섞인다. 적 핵을 부수면 그 출현 지점이 사라진다
  - 적 핵에서 9칸 안에는 건물을 지을 수 없고, 포탑은 적 건물을 쏘지 않는다. **유닛을 공격 태세로 보내야만** 부술 수 있다 (적 유닛이 없을 때 가까운 적 건물부터 친다)
  - 지상 유닛은 적 건물을 넘어 다니지 못한다. 적은 자기 건물을 그냥 지나다닌다
  - 적 건물을 부수면 전리품이 들어오고, 거점 지역의 첫 점령 보상(기지 생산량)은 두 배다
- 마지막 웨이브에는 언제나 보스가 한 마리 섞여 나온다: 보통 지역은 심연 대장, 10의 배수 지역은 더 강한 심연 군주
- 적은 핵으로 걸어오고, 길이 막히면 약한 건물을 부수고 온다. 핵이 부서지면 패배, 마지막 웨이브까지 막으면 점령
- 점령하면 핵에 남은 자원이 전부 기지로 돌아온다. 패배하면 모두 잃고, 후퇴하면 절반만 돌아온다

### 점령 보상 (지역을 처음 점령했을 때)
- 기지 생산량이 영구히 늘어난다: 지역 번호에 따라 철광 +3/분, 황석 +1.5/분, 심연 결정 +0.75/분(지역 12 부터)
- 정해진 지역에서 새 연구·결정 채굴장·가공 건물이 열린다 (`Research.cs` 의 `reqRegion`)

세이브: `persistentDataPath/save.json` (심연별 점령 지역, 연구 단계, 기지 재고·건물 단계, 출격 설정). 자원이 3종이던 예전 세이브는 값을 그대로 옮겨 읽는다. 지역 진행 중 저장은 없다.

## 조작

| | 터치 | 마우스·키보드 |
|---|---|---|
| 맵 이동 | 도구 없이 한 손가락 끌기, 또는 두 손가락 | 도구 없이 왼쪽 끌기, 오른쪽·가운데 끌기 |
| 확대 | 두 손가락 벌리기 | 휠 |
| 설치 | 건물 고르고 탭, 끌면 한 줄 (건설 줄은 옆으로 넘긴다) | 같음, 숫자 1~9 로 건물 선택 |
| 공장 | 공장 탭 → 유닛 고르기·집결 지점 | 같음 |
| 지휘기 | 핵 탭 → 보낼 곳 탭 | 같음 |
| 철거 / 해제 | 아래 버튼 | X / Esc |

## 폴더

- `Assets/Scripts/Sim` — 규칙과 시뮬레이션. UnityEngine 을 쓰지 않는 순수 C# (`noEngineReferences`). 60틱 고정, 같은 시드면 같은 결과
  - `Content.cs` 자원·건물·유닛·적·심연 정의 / `Research.cs` 연구와 기지 규칙(`BaseRules`: 채굴·가공·비용·점령 보상) / `World.cs` 타일·건물(포탑·공장) / `Units.cs` 유닛 이동·전투·길찾기 / `Gen.cs` 맵 생성 / `Waves.cs` 지역 규칙·웨이브 / `FlowField.cs` 길찾기 / `Sim.cs` 한 틱 / `AutoBot.cs` 점검용 자동 플레이
- `Assets/Scripts/Game` — 화면. 씬에는 카메라만 있고 `Bootstrap` 이 전부 코드로 만든다
  - `GameManager.cs` 화면 전환·세이브·기지 경제·진행 / `Screens.cs` 기지·심연 선택·지역 지도 / `ResearchTree.cs` 연구 트리 화면 / `Hud.cs` 전투 HUD·결과 / `PlayController.cs` 카메라·건설 조작 / `GameView.cs` 월드 그리기 / `Art.cs` 임시 그림 / `Ui.cs` uGUI 도우미
- `Assets/Editor/ProjectSetup.cs` — 초기 설정, 빌드 (메뉴 `AbyssDefense/…`)
- `Tools/SimCheck` — 규칙만 콘솔에서 검사 (Unity 없이)

## 그림 바꾸기

지금 그림은 `Art.cs` 가 코드로 그린 임시 도형이다. `Assets/Resources/Art/{이름}.png` (스프라이트, 한 칸 = 48px, 적·포신은 오른쪽을 보게) 를 넣으면 그 이름의 그림을 대신 쓴다.
이름: `block_{key}`, `block_{key}_top`(포신), `icon_{key}`(건설 버튼), `enemy_{key}`, `unit_{key}`, `item_{key}`, `fx_circle`, `fx_ring`, `fx_disc`. key 는 `Content.cs` 참고.

`-autoshot` 은 `_done.txt`(예외 수), `_checks.txt`(기지 생산·가공·출격·건설 조작·점령 보상·연구·후퇴·공장과 유닛 조작의 실제 값과 기대값), 예외가 있으면 `_errors.txt` 를 남긴다. 점검 창이 떠 있는 동안 그 창을 클릭하면 결과가 달라질 수 있다.

## 밸런스

봇 기준 초안이다. `Tools/SimCheck` 는 "지역 60쯤 열린 연구를 모두 끝낸다"고 가정한 연구 단계와 출격 한도만큼의 자원을 주고 봇을 돌린다. 가공 자원은 그 가공 건물이 열린 뒤부터 한도의 절반씩 가져가고, 봇은 포탑을 몇 개 세운 뒤 로봇 공장과 비행장을 하나씩 짓는다. 이 조건에서 봇은 지역 1~5 는 대체로 이기고(서리 심연 지역 2 는 진다), 군주가 나오는 지역 10 과 그 뒤는 심연에 따라 갈리며, 적 거점 지역은 봇이 유닛을 조금씩 흘려보내기 때문에 모두 진다. 거점 15 는 돌격 로봇·폭격기 8대를 한꺼번에 보내면 깨진다 (`dotnet run -c Release -- trace 0 15 8`). 적이 약하다는 플레이 의견으로 적 체력·수·공격력과 거점 수치를 올린 상태이며, 사람이 플레이해 맞춘 값은 아니다.
